## One loop keyword

 `for` is the only loop. It can:

 - go over a range of numbers;
 - run while a condition holds;
 - run until `break`.

 `continue` goes on to the next pass. Later pages show `for` over arrays and
 slices too.

```peeper
for i, v in 10..13 {            // the pass number, from 0, and the value
for n < 100 {                   // while `n < 100`
for {                           // until `break`
```

```peeper
fn main() {
    print("range:");
    for i in 0..5 {
        print("", i);
    }
    println();

    print("numbered:");
    for i, v in 10..13 {            // the pass number, from 0, and the value
        print("", i, v);
    }
    println();

    let mut passes = 0;
    for 0..3 {                      // no name for the value
        passes = passes + 1;
    }
    println("passes:", passes);

    let mut n = 1;
    for n < 100 {                   // while `n < 100`
        n = n * 3;
    }
    println("while:", n);

    let mut x = 0;
    for {                           // until `break`
        x = x + 1;
        if x == 4 {
            break;
        }
    }
    println("forever:", x);

    print("odd:");
    for v in 0..10 {
        if v % 2 == 0 {
            continue;
        }
        if v > 7 {
            break;
        }
        print("", v);
    }
    println();
}
```

## Ranges

 - `a..b` counts from `a` up to, but not including, `b`.
 - `a..=b` includes `b`.
 - `:step` steps by more than 1.

 A range counts down when `a` is larger than `b`, and it never wraps past the
 end of its type.

 A range is a value of type `range[T]`. You can keep it in a variable, pass
 it, return it and copy it, like a number. A step of 0 stops the program
 while it runs; the [Panics](/docs/basics/panics) page shows how.

```peeper
fn evens(below: i32) -> range[i32] {
    return 0..below:2;
}
```

```peeper
fn evens(below: i32) -> range[i32] {
    return 0..below:2;
}

fn total(values: range[i32]) -> i32 {
    let mut sum = 0;
    for v in values {
        sum = sum + v;
    }
    return sum;
}

fn main() {
    print("up:");
    for v in 0..5 { print("", v); }
    println();
    print("inclusive:");
    for v in 0..=5 { print("", v); }
    println();
    print("step:");
    for v in 0..10:3 { print("", v); }
    println();
    print("down:");
    for v in 5..=0:2 { print("", v); }
    println();
    print("top of u8:");
    for v in 250u8..=255 { print("", v); }
    println();

    let r = 1..=4;
    let copy = r;
    println("totals:", total(r), total(copy), total(evens(9)));
}
```
