## A type as a parameter

 `const T: type` is a parameter that takes a type. The call writes the type
 where a value would go, and the function uses `T` as a type. Each type a
 function is called with makes its own copy of the function, checked for
 that type.

<Terminal run="auto">

```peeper
struct Point { x: i32, y: i32 }

// The element at `index` of `list`, which the result borrows.
fn At(const T: type, list: &[]T, index: usize) -> &T in list {
    return &list[index];
}

fn main() {
    let numbers = [3]i64{10, 20, 30};
    let points = [2]Point{Point.{ x = 1, y = 2 }, Point.{ x = 3, y = 4 }};
    println(At(i64, &numbers, 2).*, At(Point, &points, 1).x);
}
```

</Terminal>

 A copy that does not work for its type is an error that names the copy:

<Terminal run="auto">

```peeper
fn Double(const T: type, value: T) -> T {
    return value + value;
}

fn main() {
    println(Double(i32, 2), Double(bool, true));
}
```

</Terminal>

## A value as a parameter

 `const n: i64` takes a value known while compiling, and the body uses it as a
 constant. The argument can be a literal, a constant, or a call that runs
 while compiling.

<Terminal run="auto">

```peeper
fn Scaled(const factor: i64, x: i64) -> i64 {
    const Twice: i64 = factor * 2;
    return x * Twice;
}

fn Three() -> i64 {
    return 3;
}

fn main() {
    println(Scaled(3, 10), Scaled(Three(), 1));
}
```

</Terminal>

 A variable is not known while compiling, so it cannot be the argument:

<Terminal run="auto">

```peeper
fn Scaled(const factor: i64, x: i64) -> i64 {
    return x * factor;
}

fn main() {
    let x: i64 = 3;
    println(Scaled(x, 1));
}
```

</Terminal>

## size_of and align_of

 `size_of(T)` is how many bytes a `T` takes, and `align_of(T)` is the number
 its address must be a multiple of. Both give a `usize` constant for the
 machine being built for, so they also work in constants and in a function
 that takes `const T: type`.

<Terminal run="auto">

```peeper
struct Node { value: i32, weight: f64 }

fn Bytes(const T: type, count: usize) -> usize {
    return size_of(T) * count;
}

const NodeBytes = size_of(Node);

fn main() {
    println(size_of(i8), size_of(i32), align_of(u64));
    println(NodeBytes, align_of(Node), size_of([4]i32));
    println(size_of(&str), size_of(&[]i32), Bytes(Node, 3));
}
```

</Terminal>

## Not supported yet

 - Leaving out the type at the call: `At(i64, ...)` always names `i64`.
 - A `const` value whose type is a type parameter: `const value: T`.
 - A `const` parameter on a C function, or on a method an interface lists.
