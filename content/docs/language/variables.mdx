## Variables

 `let` names a value, and `mut` lets it change. Without a type, a variable
 takes the type of its value.

```peeper
let fixed = 5;                  // `i32`, from the value
let mut total: i64 = 0;
```

Changing a variable declared without `mut` is an error:

<Terminal run="auto">

```peeper
fn main() {
    let count = 1;
    count = 2;
    println(count);
}
```

</Terminal>

A `let` without a value is set by its first assignment. It must be set once
 on every path before it is read:

```peeper
let result: i32;                // set below, once on each path
if value > 0 {
    result = 1;
} else if value < 0 {
    result = -1;
} else {
    result = 0;
}
```

If one path can skip the assignment, the compiler shows that path:

<Terminal run="auto">

```peeper
fn pick(flag: bool) -> i32 {
    let value: i32;
    if flag {
        value = 1;
    }
    return value;
}

fn main() {
    println(pick(true));
}
```

</Terminal>

A block can declare names of its own, which hide outer names until the block
 ends. A parameter can be `mut` too.

<Terminal run="auto">

```peeper title="examples/04_variables.peep"
// Variables: `let` names a value and `mut` lets it change. A `let` without
// a value is set by its first assignment, once on every path before it is
// read. A block may declare names of its own.
// Run: peeper run examples/04_variables.peep
fn sign(value: i32) -> i32 {
    let result: i32;                // set below, once on each path
    if value > 0 {
        result = 1;
    } else if value < 0 {
        result = -1;
    } else {
        result = 0;
    }
    return result;
}

fn next(mut count: i32) -> i32 {    // a `mut` parameter
    count = count + 1;
    return count;
}

fn main() {
    let fixed = 5;                  // `i32`, from the value
    let mut total: i64 = 0;
    total = total + fixed;
    total = total * 2;
    {
        let fixed = 100;            // hides the outer `fixed` in this block
        total = total + fixed;
    }
    println("total:", total, "fixed:", fixed);
    println("signs:", sign(-8), sign(0), sign(3));
    println("next:", next(fixed));
}
```

</Terminal>

## Conditions

 `if`, `else if` and `else` take a `bool`. `&&` and `||` skip their right side
 when the left side already decides the answer, and `!` negates.

<Terminal run="auto">

```peeper title="examples/05_conditions.peep"
// Conditions: `if`, `else if` and `else` take a `bool`. `&&` and `||` skip
// their right side when the left decides, and `!` negates.
// Run: peeper run examples/05_conditions.peep
fn describe(n: i32) {
    if n < 0 {
        println(n, "is negative");
    } else if n == 0 {
        println(n, "is zero");
    } else {
        println(n, "is positive");
    }
}

fn noisy(value: bool) -> bool {
    println("  noisy runs");
    return value;
}

fn main() {
    describe(-3);
    describe(0);
    describe(8);
    println("and:", false && noisy(true));  // `noisy` does not run
    println("or:", true || noisy(false));   // nor here
    println("both:", true && noisy(true));  // here it does
    println("not:", !(1 > 2));
}
```

</Terminal>
