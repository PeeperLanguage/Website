Peeper is an experimental systems programming language. Its compiler checks a
program's types, paths, moves and borrows, then builds a native executable
through LLVM.

<Callout type="warn" title="Pre-release">
  Peeper is pre-release software. The language, the package format and the
  compiler's interfaces may change without notice. The compiler is being
  rebuilt in Rust; this site describes what the rebuild does today.
</Callout>

## A first program

<Terminal run="auto">

```peeper title="src/main.peep"
fn square(x: i32) -> i32 {
    return x * x;
}

fn main() {
    let mut total = 0;
    for i in 1..=3 {
        total = total + square(i);
    }
    println("sum of squares:", total);
}
```

</Terminal>

## What the compiler does today

- **Parses with recovery.** A syntax error does not stop the rest of the file
  from being read, and many errors come with a fix that `peeper fix` or an
  editor applies.
- **Checks types** of integers, floats, `bool`, C strings, arrays, ranges,
  structs, functions, constants and modules, and folds constants while
  compiling.
- **Checks paths:** a variable read before it is set, a missing `return`, and
  unreachable code.
- **Checks moves and borrows:** a struct used after it moved, or a `&mut`
  borrow while a reference to the same value is still in use.
- **Builds native programs** from MIR through LLVM and Clang, on Linux, macOS
  and Windows.
- **Answers editors** through its language server, re-checking only the
  modules an edit affects.
