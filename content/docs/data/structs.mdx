## Structs

 `struct` names a group of fields. `Name.{ field = value }` makes one, with the
 fields in any order. `.{ ... }` takes the type from where the value goes.

```peeper
struct Point { x: i32, y: i32 }
let start = Point.{ y = 2, x = 1 };
let end: Point = .{ x = 4, y = 6 };
```

 A struct's own functions and methods are declared `fn Point::name(...)`. The
 [Methods](/docs/methods/methods) page shows them.

## Moves

 A struct moves when it is assigned or passed. The old variable is then unset.
 A `mut` variable can be set again, and then it is usable again. Using a moved
 variable is an error that shows where the move happened:

<Terminal run="auto">

```peeper
struct Point { x: i32, y: i32 }

fn main() {
    let point = Point.{ x = 1, y = 2 };
    let taken = point;
    println(point.x, taken.x);
}
```

</Terminal>

<Terminal run="auto">

```peeper
struct Point { x: i32, y: i32 }
struct Line { start: Point, end: Point, weight: f32 }
struct Empty {}

fn length(line: Line) -> i32 {      // takes the line, moved in
    return line.end.x - line.start.x + line.end.y - line.start.y;
}

fn main() {
    let start = Point.{ y = 2, x = 1 };
    let end: Point = .{ x = 4, y = 6 };
    let mut line = Line.{ start = start, end = end, weight = 1.5 };
    line.start.x = 0;               // a field of a field
    line.weight = 2.0;
    println("line:", line);
    println("fields:", line.start.x, line.end.y, line.weight);
    println("length:", length(line));   // `line` moves; it is unset now

    let mut point = Point.{ x = 1, y = 1 };
    let taken = point;              // moves `point`
    point = Point.{ x = taken.y, y = 5 };   // set again, so usable
    println("again:", point, taken);
    println("empty:", Empty.{});
}
```

</Terminal>

## Type aliases

 `type Name = T` gives `T` another name. Values of the alias and of `T` mix
 freely, and an alias can name a type declared after it.

<Terminal run="auto">

```peeper
type Distance = Meters;
type Meters = i32;
type Origin = Point;
struct Point { x: Meters, y: Meters }

fn double(length: Meters) -> Distance {
    return length * 2;
}

fn main() {
    let limit: Meters = 40;
    let half: Meters = 21;
    let whole: i32 = double(half);  // a `Distance` is an `i32`
    let home: Origin = Point.{ x = 0, y = whole };
    println("whole:", whole, "over limit:", whole > limit, "home:", home);
}
```

</Terminal>
